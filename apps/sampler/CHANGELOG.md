# Changelog

## 1.1.2 — 2026-11-12

- Version bump for clean `@duyojs/duyo` `1.1.2` workspace release.

## 1.1.1 — 2026-11-12

- Updated for Duyo 1.1.1 (`remochi.Input` `onenter` and regenerated view/kind types).

## 1.1.0 — 2026-11-01

Two Onyx sections, "Onyx controls" and "Onyx menus and pickers", covering the `onyx.*` kinds, including the webOS sliding panes, dividers, swipeable rows and dialogs.

## 1.0.0 — 2026-10-29

First release of the Duyo Sampler, as part of Duyo 1.0.0.

- Every `remochi.*` kind in dark and light.
- Two sections written as views, including a spec loaded at run time.

The full release notes for every package are in the repository's
[CHANGELOG.md](https://github.com/achunt2143/duyo/blob/main/CHANGELOG.md).
