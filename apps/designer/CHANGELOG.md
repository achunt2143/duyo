# Changelog

## 1.0.0 — 2026-10-29

First release of the Duyo Designer, as part of Duyo 1.0.0.

- A visual editor for views: palette, live canvas, drag and drop, component tree, inspector, undo.
- Code-behind and JSON editors; the → beside an event writes its handler.
- Run mode with the real code-behind, in device frames.
- Projects: file manager, folder browser, recent projects, `duyo.config.json`.
- GitHub: clone from your repositories, commit, push, pull, branch, pull requests; zip import and download.
- Built from Remochi components; dialogs, menus and lists follow the theme.

The full release notes for every package are in the repository's
[CHANGELOG.md](https://github.com/achunt2143/duyo/blob/main/CHANGELOG.md).
