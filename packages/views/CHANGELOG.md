# Changelog

## 1.0.0 — 2026-10-29

First release of `@duyo/views`, as part of Duyo 1.0.0.

- `.view.json` design plus code-behind, with generated `.view.gen.ts` types.
- Spec validation with JSON paths (`DUYO_VIEW_001` to `DUYO_VIEW_008`).
- `duyo-views [dir] [--check]` CLI and the `@duyo/views/vite` plugin.
- `generateKindTypes`, `formatSpec`, and the browser-safe `@duyo/views/spec`.
- `loadSpec` (`@duyo/views/load`) for specs that arrive at run time, with trust levels.

The full release notes for every package are in the repository's
[CHANGELOG.md](https://github.com/achunt2143/duyo/blob/main/CHANGELOG.md).
