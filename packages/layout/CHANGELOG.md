# Changelog

## 1.0.0 — 2026-10-29

First release of `@duyo/layout`, as part of Duyo 1.0.0.

- `duyo.FittableRows` and `duyo.FittableColumns` as a pure flexbox resolver.
- `fit`, `gap`, `padding`, `align`, `justify`, `fill` and `noStretch`, with spacing from theme variables.

The full release notes for every package are in the repository's
[CHANGELOG.md](https://github.com/achunt2143/duyo/blob/main/CHANGELOG.md).
