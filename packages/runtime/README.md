# @duyo/runtime (archived)

> **Archived.** This is the first Duyo iteration: vendored Enyo 2.7 bundled with Rollup. The built `build/enyo.js` does not expose `enyo.kind` / `enyo.Control`, and the approach is being replaced by a TypeScript runtime. See the root [README](../../README.md) and the `archive/enyo-2.7-runtime` tag.

`framework/` holds the Enyo 2.7 source (Apache 2.0, see [LICENSE-2.0.txt](LICENSE-2.0.txt)), committed to this repo. `ENYO_SETUP.md` describes how it was originally vendored.
